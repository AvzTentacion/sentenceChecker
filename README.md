# Sentiment Analysis AI

This simple Python project checks whether a sentence is positive or negative. It isn't entirely acurate because that would require a big data set and a better algorithm this just works on recognition of the words on the dataset i created.

---

## How to Run This Project

Follow these 3 easy steps to get started:

### Step 1: Install Python Libraries
Open your Terminal (Mac) or Command Prompt (Windows) and run this command:
```bash
pip install pandas scikit-learn
```

### Step 2: Create Your Files
Make sure you have these two files in the exact same folder:
*   `app.py`
*   `README.md` 

### Step 3: Run the Code
Run the script using your terminal:
```bash
python app.py
```

---

## What the Code Does
1. **Reads Text**: It looks at a few sample positive and negative sentences.
2. **Learns**: It connects positive words to a positive result and negative words to a negative result.
3. **Guesses**: You can type in a sentence and it checks whether that sentece is actually positive or negative.
